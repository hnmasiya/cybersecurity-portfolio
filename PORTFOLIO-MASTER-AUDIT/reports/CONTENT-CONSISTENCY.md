# Website / Career Content Consistency

## Standard Career Positioning

Recommended:

> SOC Analyst | Security Engineer | Cybersecurity Analyst

## Experience

This audit does not assert a years-of-experience figure. Cross-check
CAREER-TIMELINE-AUDIT.md against your own verified career start date and
make sure the CV, README, and website all state the same, confirmed
number. Do not let any single AI-drafted document overwrite a figure
you've already confirmed elsewhere without checking it first.

---

## Recommended Certification Names

- CompTIA Security+ (SY0-701)
- Google Cybersecurity Certificate
- Google IT Support Certificate
- National Diploma in Information Communication Technology
- BSc Computer Science — In Progress, if applicable

---

## Evidence Positioning

Prefer:

> Hands-on security engineering portfolio with reproducible labs,
> detection engineering, DFIR, network analysis and cloud security.

Avoid unsupported statements implying production SOC experience where the
artifact is actually a synthetic or laboratory demonstration.

## No Automatic Content Changes

This audit only reports consistency issues.

Existing website/CV content is not overwritten.
