# 1. Introduction

File Integrity Monitoring (FIM) is a security capability used to detect unauthorized changes to critical files and directories.

Wazuh uses its File Integrity Monitoring module to monitor specified files, detect modifications, additions, and deletions, and generate security alerts when changes occur.

This laboratory exercise demonstrates the use of Wazuh FIM capabilities to identify unauthorized file modifications within a monitored environment.

# 4. File Integrity Monitoring Overview

File Integrity Monitoring provides visibility into changes affecting important system resources.

Wazuh FIM can detect:

- File creation
- File modification
- File deletion
- Permission changes
- Ownership changes
- File checksum changes

These capabilities help security teams identify:

- Unauthorized system changes
- Malware activity
- Configuration tampering
- Suspicious administrative actions

# 6. FIM Testing Procedure

## 6.1 Monitored Directory

The monitored directory used during testing:

```
/etc
```

The directory was selected because it contains important Linux configuration files.

---

## 6.2 File Modification Test

A controlled test modification was performed by creating a test file:

```
sudo touch /etc/fim-test-file.txt
```

The file creation generated a File Integrity Monitoring event.

---

## 6.3 File Change Detection

The file was modified:

```
sudo echo "Wazuh FIM Test" >> /etc/fim-test-file.txt
```

Wazuh detected the change and generated an alert showing:

- File modification
- Timestamp of change
- File path
- User activity
- Integrity change information

---

## 6.4 File Removal Test

The test file was removed:

```
sudo rm /etc/fim-test-file.txt
```

Wazuh detected the deletion event.

# 8. Security Impact

File Integrity Monitoring helps detect suspicious activities such as:

- Unauthorized configuration changes
- Malware modifying system files
- Privilege escalation attempts
- Persistence mechanisms
- Insider activity
- Accidental administrative changes

Without FIM monitoring, unauthorized modifications may remain unnoticed.
