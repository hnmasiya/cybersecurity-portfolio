# Wazuh Agent Deployment Report

## Lab Overview

**Project:** Security Information and Event Management (SIEM) Lab  
**Platform:** Wazuh SIEM  
**Category:** Endpoint Monitoring  
**Environment:** Local Cybersecurity Home Lab  

---

# 1. Introduction

Wazuh agents collect security information from monitored endpoints and forward events to the Wazuh Manager for analysis.

This laboratory focused on understanding endpoint agent deployment and communication.

---

# 2. Lab Objectives

Objectives:

- Understand Wazuh agent architecture
- Deploy monitoring agents
- Verify agent communication
- Monitor endpoint security events

---

# 3. Agent Deployment Process

The deployment process included:

1. Preparing the endpoint system.
2. Installing the Wazuh agent.
3. Registering the agent with Wazuh Manager.
4. Verifying agent connectivity.
5. Monitoring generated events.

---

# 4. Agent Monitoring Capabilities

Wazuh agents provide:

- Log collection
- File integrity monitoring
- Vulnerability detection
- Security configuration monitoring
- Endpoint visibility

---

# 5. Validation

Validation included:

- Confirming agent registration
- Checking dashboard visibility
- Reviewing received events
