# Wazuh SIEM Log Analysis Report

## Lab Overview

**Project:** Security Information and Event Management (SIEM) Lab  
**Platform:** Wazuh SIEM  
**Category:** Log Analysis and Security Monitoring  
**Environment:** Local Cybersecurity Home Lab  
**Deployment:** Docker Container Environment  
**Operating System:** Zorin OS  

---

# 1. Introduction

Log analysis is a critical SIEM capability used to identify suspicious activity, investigate security events, and support incident response.

This laboratory exercise focused on reviewing security events collected by Wazuh and understanding how logs can be analyzed for threat detection.

---

# 2. Lab Objectives

Objectives:

- Analyze security events within Wazuh
- Understand log collection and normalization
- Review generated alerts
- Identify suspicious activity patterns
- Improve security monitoring skills

---

# 3. Log Sources Reviewed

| Source | Purpose |
|---|---|
| Linux System Logs | Operating system activity monitoring |
| Authentication Logs | User login monitoring |
| Wazuh Alerts | Security event detection |
| Agent Events | Endpoint monitoring |

---

# 4. Analysis Process

The investigation process included:

1. Accessing the Wazuh Dashboard.
2. Reviewing collected security events.
3. Filtering alerts by severity.
4. Examining event details.
5. Identifying potential security risks.

---

# 5. Findings

The analysis demonstrated how Wazuh can:

- Collect endpoint logs
- Detect suspicious activity
- Provide security visibility
- Support investigation workflows
