# Security Information and Event Management (SIEM) Lab Operations

## 🔍 Overview
This directory contains architectural documentation, ingestion configurations, and analysis reports for deployed and controlled SIEM platforms. Operations focus on centralizing event logs, tuning alerting mechanics, and monitoring host telemetry for active indicators of compromise.

## 📁 Active Modules
* **[Wazuh SIEM Deployments](./Wazuh/Reports/Alert-Investigation.md)** — Central host intrusion monitoring and SSH brute-force log analysis.
* **[Splunk SOC Lab Track](./Splunk/)** — Hands-on Splunk investigation track; Lab 01 currently contains a synthetic SSH-authentication dataset and SPL query pack. Splunk execution evidence is required before the work is classified as completed.

## Evidence classification

Splunk material is explicitly classified by execution state. Synthetic datasets and query packs are training preparation; executed searches require retained screenshots or exported results; live telemetry requires an authorized real environment.
