# Splunk Lab 01 Evidence Capture

This directory is intentionally empty until the lab is executed.

## Capture after execution

Save only sanitized, reproducible evidence such as:

- `01-data-ingestion.png`
- `02-baseline-search.png`
- `03-failure-analysis.png`
- `04-timeline.png`
- `05-timechart.png`
- `investigation-report.md`

## Evidence standard

Every retained artifact should make it possible to answer:

- What was executed?
- When was it executed?
- Against which synthetic dataset?
- What result was observed?
- What conclusion was supported?
- What limitations remained?

Do not store credentials, tokens, private infrastructure details, or unrelated screenshots.
