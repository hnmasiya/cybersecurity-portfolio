# Phishing & Business Email Compromise Lab

A defensive email-investigation case study covering suspicious email analysis, headers, SPF/DKIM/DMARC, URL/domain analysis, attachment IOC extraction, account compromise, detection and incident-response timeline.

Safety: all messages, domains, IPs and attachments are synthetic. No credential-harvesting infrastructure is included.

Scenario: a finance user reports an urgent supplier-payment request. Preserve the original message, inspect authentication and routing, extract IOCs, assess identity impact, create a detection and recommend containment.

Evidence: evidence/email-investigation.json, detections/phishing-bec-detection.yaml, reports/INCIDENT-RESPONSE.md.
