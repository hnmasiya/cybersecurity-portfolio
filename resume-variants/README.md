# Global Resume Variants

The repository maintains one verified master resume and generates country/application variants from it.

## Variants

- Global / International
- UK
- Europe
- Canada
- United States
- Australia / New Zealand
- Middle East
- Africa
- Asia-Pacific

The generator changes presentation conventions only. It does not invent employers, qualifications, work authorization, salary, security clearance, nationality, or other claims.

Country-specific work authorization should be supplied only when verified for the individual application.

Generated PDFs are written to `dist/resumes/` during CI and are not intended to become separate manually maintained source documents.
