# Security Audits & Vulnerability Assessment

## Overview & Summary
* **Lab Context:** Google Cybersecurity Professional Certificate Module.
* **Summary:** In this lab, I applied the NIST Cybersecurity Framework (CSF) to conduct a security audit for a mock business environment. I identified critical asset vulnerabilities, mapped compliance gaps against NIST functions (Identify, Protect, Detect, Respond, Recover), and created an actionable remediation plan to strengthen organizational posture.
