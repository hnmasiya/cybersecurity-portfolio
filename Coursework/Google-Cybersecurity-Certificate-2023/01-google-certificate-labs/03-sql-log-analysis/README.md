# SQL Database Security & Log Analysis

## Overview & Summary
* **Lab Context:** Google Cybersecurity Professional Certificate Module.
* **Summary:** Using SQL database queries, I analyzed system login logs to investigate unauthorized access attempts occurring outside standard business hours. I constructed multi-condition WHERE clauses, pattern-matching filters (`LIKE '%login%'`), and JOIN statements to isolate failed login metrics. The results provided a clear list of suspicious IP addresses for the incident response team.
