# Linux File Permissions & Least Privilege Audit

## Overview & Summary
* **Lab Context:** Google Cybersecurity Professional Certificate Module.
* **Summary:** This exercise focused on auditing system access controls in a Linux server environment using core terminal commands (`chmod`, `chown`, `ls -l`). I identified over-privileged user groups and modified file permissions to enforce the Principle of Least Privilege (PoLP). This ensured sensitive directory access was restricted strictly to authorized staff.
