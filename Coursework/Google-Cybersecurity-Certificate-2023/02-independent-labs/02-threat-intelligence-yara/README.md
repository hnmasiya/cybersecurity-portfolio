# Threat Intelligence & YARA Detection Engineering

## Objective

Develop and document a YARA detection rule for identifying suspicious Windows credential-dumping or memory-dumping indicators.

This independent lab demonstrates indicator selection, static detection logic, rule construction, false-positive analysis, and reproducibility.

## Detection Artifact

- `suspicious_binary.yar`

## Rule Overview

The rule is named:

```text
Detect_Suspicious_Memory_Dump
```
