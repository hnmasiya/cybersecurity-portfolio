# Public Source of Truth

The public cybersecurity portfolio is published from this private development repository:

`hnmasiya/cybersecurity-portfolio-dev`

Development work, security validation and quality checks are performed here before a deliberate manual publication to `hnmasiya/cybersecurity-portfolio`.

The public repository is a release artifact. Its `main` branch is intentionally kept free of development GitHub Actions workflows and is protected by active repository rulesets.

See [PRODUCTION-PUBLISH-POLICY.md](PRODUCTION-PUBLISH-POLICY.md) for the complete publication-control model.
