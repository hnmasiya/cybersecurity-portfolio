# Python Automation for Access Control Lists

## Overview & Summary
* **Lab Context:** Google Cybersecurity Professional Certificate Module.
* **Summary:** I created a Python script designed to automate the management of network access control lists (`allow_list.txt`). The script opens designated configuration files, converts data into iterable Python lists, and uses conditional statements to filter out revoked IP addresses. This automated process replaces manual list editing, drastically reducing human error in security maintenance.
