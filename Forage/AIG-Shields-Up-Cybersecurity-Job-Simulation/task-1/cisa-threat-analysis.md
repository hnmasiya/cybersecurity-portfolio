# Task 1 — CISA Threat Analysis

## Objective

Review CISA security advisories and understand how vulnerability intelligence should inform infrastructure remediation and incident-response decisions.

## Focus

The simulation covered advisories relating to:

- Log4j / CVE-2021-44228 (Log4Shell).
- Ransomware.

The exercise required interpreting the security significance of the advisories and identifying what infrastructure should be investigated or remediated.

## Key Analysis

For Log4Shell, the investigation focused on determining whether the affected Log4j component was present in the supplied environment and ensuring that remediation guidance addressed both directly installed and bundled dependencies.

## Operational Security Workflow

**Advisory → vulnerability → affected technology → asset inventory → owner → remediation → validation**

## Scope

This document reflects the controlled Forage exercise and does not represent a real AIG vulnerability assessment.
