# Career Intelligence Suite

This directory contains deterministic job-search and application-tracking automation.

## What it does

- Searches public job APIs on a schedule.
- Filters roles against the configured cybersecurity target roles.
- Produces a dated Markdown and CSV job report.
- Maintains a simple application tracker.
- Generates a weekly application summary.
- Provides a job-tailoring brief that extracts requirements and maps them to verified resume evidence.

## Evidence rules

The automation never invents employment, certifications, metrics, tools, clearance, sponsorship, or experience. It only uses the resume and portfolio evidence already present in this repository.

Job-board data is a discovery aid. Always open the original employer/ATS application page before applying.

The Remotive public API is used only for discovery and attribution; its published terms require linking to the Remotive job URL and identifying Remotive as the source. See the source documentation before changing this integration.
