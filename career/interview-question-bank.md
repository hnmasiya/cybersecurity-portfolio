# Cybersecurity Interview Preparation

Use this as a truthful preparation bank. Answers must be based on verified experience, independent labs, coursework, and clearly labelled Forage simulations.

## SOC / SIEM
1. Walk through how you would triage a suspicious authentication alert.
2. How would you distinguish a false positive from a true security event?
3. Explain how you have used Wazuh and Sysmon in a lab.
4. How would you investigate repeated failed logins followed by a successful login?
5. How do MITRE ATT&CK techniques help structure an investigation?

## Incident Response / DFIR
1. Describe an incident-investigation workflow from detection through recovery.
2. What evidence would you preserve first?
3. How would you protect evidence integrity?
4. Explain the difference between an observed indicator and proof of compromise.
5. Describe the simulated ransomware investigation completed through the Datacom Forage simulation.

## Windows / Active Directory
1. How do authentication and privilege events help security monitoring?
2. Explain least privilege and RBAC.
3. How would you investigate an unexpected privileged-group membership change?
4. What security telemetry would you collect from Windows endpoints?

## Network Security
1. Walk through a PCAP investigation.
2. What indicators can be extracted from network traffic?
3. How would you investigate suspicious DNS or HTTP traffic?

## Behavioural
1. Tell me about a difficult technical incident you solved.
2. Describe a time you had to explain a technical issue to a non-technical stakeholder.
3. How do you prioritize multiple incidents?
4. How do you keep your cybersecurity knowledge current?

## Evidence rule
Do not present a lab, coursework exercise, or Forage simulation as paid production experience.
