# Application Submission Policy

1. Discovery and preparation may be automated.
2. Sponsorship must be verified from employer/recruiter wording or an authoritative source.
3. Every application must have a canonical vacancy identity before submission.
4. Duplicate vacancies across boards must resolve to one canonical record.
5. The user must approve an application before submission unless a separately connected and explicitly authorized integration permits the action.
6. Never bypass CAPTCHA, MFA, anti-bot controls, access controls, or site restrictions.
7. Never fabricate answers to screening questions.
8. If a form asks for information not in the verified candidate record, pause for user input.
9. Record the application URL, date, method, and confirmation/reference after submission.
10. If no authorized submission integration exists, provide the official application URL and keep status at Pending approval or Manual application.
